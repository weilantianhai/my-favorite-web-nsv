# My Favorite Web — 我的常用网站导航

> 一个极简、美观的毛玻璃风格个人导航页，支持深色/浅色主题切换与跟随系统。

📝 **项目备注：** 本页面由 DeepSeekHarness + DeepSeek-V4-flash 生成，是作者学习 **Vibe Coding**（AI 对话式编程）和 **GitHub 仓库管理**的练手作品，同时也用来收藏和记录自己认为有价值的网站。

🔗 **在线地址：** <https://weilantianhai.github.io/my-favorite-web-nsv/my-nav.html>

---

## 特性

- 三档主题切换 — 深色 / 跟随系统 / 浅色，一键切换，偏好自动保存到本地
- 跟随系统 — 实时监听系统主题变化，无需手动刷新
- 毛玻璃设计 — 深色半透明 + 浅色淡蓝玻璃质感，鼠标跟随光晕动效
- 彩色渐变背景 — 紫、粉、蓝三色径向渐变，营造沉浸氛围
- 响应式布局 — 桌面 3 列、平板 2 列、手机 1 列，完美适配各种屏幕
- 零框架依赖 — 纯 HTML + CSS + JavaScript，加载极快

## 设计亮点

### 主题系统
采用 CSS 自定义属性（--bg、--text、--card-bg 等）统一管理颜色，data-resolved 属性始终反映实际可见主题，切换动画平滑自然。

### 毛玻璃卡片
- 深色模式：半透明白色玻璃
- 浅色模式：淡蓝色毛玻璃（rgba(219, 234, 254, 0.6)）

### 三档切换开关
点击循环：深色 -> 跟随系统 -> 浅色 -> 深色，滑块三个位置对应三种模式，文字提示同步显示当前模式。
